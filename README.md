# FreeRTOS Assignment

FreeRTOS simulations written in C for Windows.

## Deliverables

1. Autonomous Campus Parking Management System
   - Monitor parking bays.
   - Allocate bays with VIP priority.
   - Release bays when vehicles exit.
   - Log parking events with timestamps.

2. Automated Industrial Sensor Monitoring System
   - Update pressure every 5 seconds.
   - Update vibration every 7 seconds.
   - Display and log sensor readings.
   - Protect shared variables using FreeRTOS mechanisms.

3. Smart Intersection Traffic Signal Controller
   - Coordinate North–South and East–West lights.
   - Display and log traffic light transitions.

4. Embedded Systems Discussion
   - Hardware, memory and timing constraints.
   - Reliability, validation and fault tolerance.
